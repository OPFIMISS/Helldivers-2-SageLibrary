# 原版风格图标与简中文案

## 绘制图标

1. 用本机游戏截图或可读取的同类原版图标作主参考。至少挑同一战备类型的两个图标，看轮廓、负形、留白、白色功能符号和缩小时的可辨识度。不要把参考图当可分发的资产；默认绘制新的图形。
2. 先画**所属装备类别的主体轮廓**，再加一个**区分功能**的符号。例如哨戒炮先画炮塔与底座，再用射束轮廓表现特性；支援背包保留背包形状；轨道类优先用投送轨迹或落点表达，避免和手持武器读成一类。先作几何稿（例如 SVG 或矢量软件路径），不要加文字、渐变、阴影、表面纹理或细碎装饰。对照同类原版的视觉重量、留白和画面重心，不强制统一像素边距。
3. 在拟装载界面的深底上，以约 24–40 px 检查分类色/白色预览，而非直接看红绿原图。主体和特征应不用放大就能分辨；有碰撞的细线改为实面或扩大负形。导出 `256 × 256` PNG，再核对输出通道。
4. 建议直接画 HellForge 的 `raw` 通道：黑底留空、红 `#FF0000` 为游戏分类色遮罩、绿 `#00FF00` 为白色标记遮罩，蓝通道留零。黑底可以是样本那样的实黑；不要仅靠 alpha 预想引擎效果。已有红白稿可先用 `"prepare": "auto"`，交付前看转换是否正确；已是红绿遮罩就用 `raw`，不混用。`"prepare": "image"` 是保留图片色彩的普通部件用途，不用于战备分类染色。

本机观察：别西卜的 `images/flak_sentry.png` 用红色炮塔、底座配绿色散射提示；`images/orbital_arc_barrage.png` 用红色底形、绿色下落符号和电弧；维克斯的 `images/pc130.png` 等也直接给红绿遮罩。弗兰克斯样本存在不同原稿颜色且常用 `auto`，不能只看 PNG 文件名照搬导出设置。样本只能说明其实现习惯，原版风格应以游戏里的同类图标为准。

## 将图标接到战备

`hellforge-data.json` 最小结构示意：

```json
{
  "format": 1,
  "patches": [
    {
      "archives": ["007e093ca718ca1a"],
      "resources": [
        {
          "icon": "icons/example.png",
          "name": "author/pack/icons/example",
          "prepare": "raw"
        }
      ]
    }
  ]
}
```

`HfStratagem.icon` 要写 `author/pack/icons/example`，不是 PNG 路径、模组清单的封面图或手算出的资源哈希。构建器用 `icon` 同时生成纹理和 GUI 材质；两者都要随会话正确部署。若只成功生成图像或构建仍未就绪，用 `icon = NULL` 沿用基底；指向缺失的材质可能使游戏崩溃。最终在出击配装和任务内 HUD 都检查该图标；别把小图标、模组封面、武器纹理或座舱图形混成一条资源链。

## 写出像原版的简中

- **名称**：先识别类别，再给独特功能或代号。样式示意：`轨道电弧火力网`、`高射哨戒炮`、`“棱镜”外骨骼装甲`。若实体 `designation` 已显示型号，确认组合效果，避免界面出现两份型号；独立战备在需要时才把型号写进标题。
- **说明**：第一句讲投送什么、怎么作用；第二句只讲关键限制、友伤或适用场景。可用官方邻近条目的词汇，例如 `战略配备`、`信标`、`超级驱逐舰`、`飞鹰`、`鹈鹕`、`火力网`、`支援武器`。战地风格一两句足够，避免把代码、原型名称、研发过程或补丁日志写进菜单。示意：「从轨道发射一轮电弧弹。电弧会在相邻目标之间跳跃，请与打击区域保持距离。」
- **准确性**：从实际玩法与配置默认值取证，核对持续时间、半径与直径、冷却与作用间隔、几次齐射与每轮弹数；面板已有的冷却和次数不必再写一遍。区分 `友军会受伤`、`只能由主机触发` 和 `需装备背包`，避免承诺源码未做的功能。开发还未实战验证时标明状态。
- **文本落点**：分别检查 `HfStratagem.title/description`，实体或武器的 `title`/`name`、`designation` 和 `description`，背包、分类标题、独立提示、清单显示名。保持 UTF-8，确认定长缓冲不会截断字符；座舱 HUD 等自画层需单独核对字体字库和排版。稳定 `name`、资源路径、配置键、存档 ID、指令及匹配用原名一律保留。原本的 `name` 在不同结构中可能是资源标识、显示名或还被用于查表，必须追踪使用方再改；为同时承担查表和显示的文本另设显示字段。
