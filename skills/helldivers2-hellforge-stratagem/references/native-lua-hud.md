# HellForge 0.4 原生模组的常驻 Lua HUD

适用 HellForge 0.4、SDK16、游戏构建25480438、Lua5.1。2026-11-25用户实测
Field Support 0.3.3后确认HUD显示正常，并认可像素小字效果。此前0.3.2虽有
Lua绘制成功日志，屏幕仍看不到能量条；不能用pcall成功代替画面验证。
本次反馈没有确认身体隐藏、联机、不同分辨率或帧率开销。

## 复用入口

[assets/optical_view.lua](../assets/optical_view.lua)保留了0.3.3实际交付的脚本。
它由原生DLL读取并注入游戏引擎Lua状态，不是可直接安装的Bingus/Chef插件。
复用时把脚本随MOD根目录打包，按以下约定提供三个原生回调。脚本还包含
角色网格隐藏；只需要HUD时保留energy_hud及其GUI辅助逻辑，重新接入自己的状态。

| 回调 | 参数与返回值 |
| --- | --- |
| `__liuli_optical_poll()` | 返回10项：单调毫秒时间、0到1的电量、激活布尔值、本地穿戴角色unit、五个迷彩根unit、挂接版本。未装备时电量为-1，没有unit时返回0。 |
| `__liuli_optical_relation(unit)` | 返回两个布尔值：是否应隐藏、是否属于要跟踪的角色或挂件。只画HUD时可以删去网格路径，避免无意义的世界扫描。 |
| `__liuli_optical_notice(message)` | 写入原生MOD日志，用于一次性错误和GUI创建记录。 |

`__liuli_optical_check()`由脚本安装，供原生桥每秒维护一次。时间使用同一
单调时钟，不能混用秒、毫秒和系统日期。

## 画到实际的UI世界

参照本机NarrowHUD的icon_world与Chef的top_world，从`Application.worlds()`
选取第一个不同于`Application.main_world()`的世界，调用
`World.create_screen_gui(overlay, 'scale', 1, 1)`。这是本构建观察到的选择规则，
换构建后重新确认世界用途。主场景screen GUI创建成功也可能不可见。
没有证据时不把问题归因于其他HUD冲突，也不修改其他MOD的GUI或全局材质。

保留一个GUI引用，以`Application.back_buffer_size()`作为布局尺寸来源。
样例按高度1080缩放，能量条位于左下x46、y160，宽128、高8，图层-20；
Chef基础HUD约为-100，菜单通常从0起。30%位置画阈值刻度，充能就绪用黄，
激活用蓝绿。位置、颜色和层数可按实际界面调整。

主世界、UI世界或世界数量变化时丢弃旧GUI引用，避免销毁已经失效的GUI。
明确卸包时仅在所属世界仍列于`Application.worlds()`时主动销毁GUI。

## 用矩形画像素数字

百分比由3x5点阵组成，字符集仅含0到9和百分号；例如0为
`111101101101111`，按每行3位展开。四字符显示区使用最多60个小矩形，
不依赖字体包、纹理或中文字库。数字用`string.format('%3d%%', rounded)`
右对齐；空格对应全透明点阵，更新时也清除旧数字的亮点。

样例每个逻辑点间距2，实心矩形大小1.6；按`height/1080`等比缩放。
将点阵首行放在字符最高y处，避免上下颠倒。用户认可的是这套实际绘制结果，
没有单独验证所有分辨率下的整数像素对齐。

## 更新频率与共存

HUD最多每100ms处理一次。每个矩形保存位置、尺寸、颜色；完全相同时跳过
`Gui.update_rect`，首次创建后不反复重建GUI。这证明代码避免重复写入，
没有进行游戏帧时间测量，不能写成性能零开销。

包装现有全局`update`和`render`，保留原调用与所有返回值，包括中间或末尾的nil。
其他MOD可能把自己的包装放到外层，不据此每秒再次包装；样例只在自身帧回调
停止超过1500ms时维护，防止不断叠加调用链。

网格效果与HUD分开节流。完整样例仅在装备、迷彩根或挂接版本变化时扫描世界，
最多4Hz；稳定激活时只检查缓存角色的网格。跨帧保存原可见布尔值，不保留原生
mesh对象；解除时恢复原值。该隐藏路径仍待用户单独确认，不能随HUD一起标为通过。

## 原生桥边界

用SDK的hook chain挂接`lua_pcall`，先识别同时有`stingray`表和`update`函数的
引擎状态，再固定Lua线程。游戏线程回调不等于Lua线程；跨线程发布原子状态快照，
不从Lua读取可变玩法结构。保存并恢复Lua栈、防止重入，记录脚本装载或pcall错误。

原生从MOD目录读取脚本时使用UTF-8到Windows宽字符路径转换及`CreateFileW`，
避免中文路径失败。只在首次进入任务时安装桥，不必等本地穿包才安装。
本构建的unit userdata按`(uintptr_t)userdata >> 2`转为handle，原生父关系恢复
使用的偏移必须另按游戏版本核对，不能泛化到新版。
